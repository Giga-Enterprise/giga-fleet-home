Security

Last updated: July 20, 2026

Municipal and enterprise operators trust GigaFleet to run mission-critical field operations. This page summarizes how we protect the platform and your data.

Infrastructure

GigaFleet runs on Google Cloud Platform. We inherit Google’s physical, network, and infrastructure security, including data centers that maintain SOC 1/2/3, ISO 27001, and other leading certifications.

Encryption

Data is encrypted in transit using TLS, and at rest using Google-managed encryption on the underlying storage and database services.

Access control & tenant isolation

  • Role-based access with least-privilege permissions across the platform.
  • Per-organization data isolation — each operator’s data is scoped to its own organization; client-portal users see only the data scoped to them.
  • Authenticated access to all application and administrative surfaces.

Application & operational security

  • Security considered throughout the development lifecycle, with code review and dependency management.
  • Activity and audit logging to support monitoring and investigation.
  • Managed backups and redundancy provided through Google Cloud services.

Incident response

We maintain an incident-response process and will notify affected customers of material security incidents in accordance with applicable law and your agreement.

Data residency

Customer data is hosted in the United States.

Compliance

GigaFleet is built on SOC- and ISO-certified Google Cloud infrastructure, and our data handling is aligned with the CCPA/CPRA. A formal SOC 2 examination of GigaFleet is on our roadmap; contact us for our current security package and status.

Reporting a vulnerability

If you believe you have found a security issue, please report it to sales@gigaent.com so we can investigate promptly. We appreciate responsible disclosure.
